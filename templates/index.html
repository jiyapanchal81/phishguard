🛡️ PhishGuard

Practical tools to help you stay safe online.

A small security awareness toolkit

PhishGuard helps everyday users make safer decisions online — check if a password is strong, spot phishing links, recognise suspicious messages, report incidents, and test what you know. It also includes a small, exploratory machine-learning demo.

🔐 Password Strength Checker

Test how strong your password really is.

🔗 Phishing URL Checker

Paste a link and find out whether it looks suspicious.

📧 Suspicious Message Checker

Paste an email or text to see if it has phishing red flags.

🎯 Security Awareness Quiz

Test what you know with five quick questions.

📝 Report an Incident

Spotted a phishing attempt? Log it in the incident database.

📋 Incident Log

Browse every phishing incident that has been reported.

🧪 ML Demo

See a rule-based check and a machine-learning model judge a message side by side.
